# 📱 Projeto FlutterFlow - Aplicação No/Low-Code

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como parte da disciplina de desenvolvimento **No/Low-Code**, utilizando a plataforma FlutterFlow com o auxílio do professor Odair. 

A aplicação foi criada do zero com o objetivo de demonstrar a construção de interfaces modernas(layout), navegação entre telas e integração com API externa e menu lateral.

**Faculdade Impacta e Tecnologia**

---

## 🌙 Nome do APP

  Foi baseado no tema da lua e o espaço. 
  O nome do app é baseado nas letra D e V, de acordo com as iniciais dos nomes dos desenvolvedores.

---

---

## 🎯 Objetivo

Desenvolver uma aplicação funcional utilizando ferramentas No/Low-Code, envolvendo:

* Criação de interfaces (UI)
* Navegação entre telas
* Integração com API
* Organização de projeto

---

## 🖥️ Funcionalidades

### 🚀 Splash Screen

* Tela inicial de carregamento
* Exibição do logo do aplicativo

### 🔐 Login

* Entrada de usuário e senha
* Estrutura básica de autenticação (ainda sem o funcionamento do backend)

### 📝 Cadastro

* Formulário para criação de novos usuários
* Campos como nome, email e senha

### 📍 Consulta de CEP (API)

* Integração com API externa para busca de endereço via CEP
* Preenchimento automático de dados (rua, cidade, etc.)

### 👥 Página de Participantes

* Exibição dos integrantes do projeto
* Informações sobre os desenvolvedores

---

## 🛠️ Tecnologias Utilizadas

* FlutterFlow (plataforma principal)
* Flutter (código exportado)
* API pública de CEP (ex: ViaCEP)

## ▶️ Como Executar

1. Clone este repositório:

```
git clone https://github.com/7offdvx/App-DV-Atividade-No-Low-Code.git
```

2. Acesse a pasta do projeto:

```
cd seu-repositorio
```

3. Instale as dependências:

```
flutter pub get
```

4. Execute o projeto:

```
flutter run
```
